# 1.0.0 — 2026-08-30

Release 1.0.0

Primeira versão pública do plugin.

### Features
- Plugin oh-my-zsh com atalhos para o fluxo git flow (AVH edition):
  `gup`, `gcMsg`, `gfs`, `gff`, `gfrs`, `gfrf`, `gfhs`, `gfhf`.
- Padrão Conventional Commits + SemVer (tags sem prefixo `v`).
- Detecção automática de `master`/`main`; publicação automática na origin
  de toda branch nova de feature/release/hotfix.
- Bônus: skill `git-flow` para o Claude Code, que orquestra as funções do
  plugin e escreve commits/changelog a partir da análise do diff.

### Docs
- README com instalação (oh-my-zsh, manual, gerenciadores de plugin).
- Manual completo das funções em `docs/git-flow-helpers.md`.
