# 1.1.3 — 2026-09-11

Hotfix 1.1.3 — mensagens multi-linha no gcMsg

- `gcMsg` agora preserva mensagens multi-linha. O assunto e o corpo iam num
  único `git commit -m`, sem a linha em branco que o git exige entre eles,
  então tudo virava assunto e o corpo ficava vazio. Argumentos posicionais
  extras também eram colados com espaço em vez de virarem linhas do corpo.
- Uma descrição de uma palavra seguida de flag (ex.: `gcMsg feat "resumo"
  --no-push`) não é mais confundida com o escopo.

- Nova flag `-m` / `--message` em `gcMsg`, repetível como no `git commit -m`:
  cada ocorrência vira um parágrafo do corpo do commit.
- Mensagem multi-linha num único argumento: a primeira linha vira o assunto e
  o restante vira o corpo.
- Modo interativo passa a perguntar um corpo opcional multi-linha, encerrado
  com Enter numa linha vazia.

- README e `docs/git-flow-helpers.md` (EN e PT) documentam as mensagens
  multi-linha e, enfim, as flags `--no-pull` e `--staged-only` da 1.1.2.
